# Shorts

YouTube Shorts for [mehmetcinar.com](https://mehmetcinar.com), made with
[Remotion](https://www.remotion.dev) and ElevenLabs voices.

```bash
bun install
cp .env.example .env            # add your ElevenLabs API key
bun scripts/voice.ts <slug> liam   # voice-over + word timings
bun run dev                     # Remotion Studio
bun run render one-evening-with-claude-code
```
